## 🚀 快速开始

### 1. 进入测试目录
```bash
cd back-end/test
```

### 2. 安装依赖（首次运行）
```bash
go get github.com/gogf/gf/v2
go get github.com/gogf/gf/contrib/drivers/mysql/v2
```

### 3. 配置数据库
编辑 `config.yaml`，修改数据库连接信息：
```yaml
database:
  default:
    link: "mysql:root:你的密码@tcp(127.0.0.1:3306)/todo_app_go_frame?charset=utf8mb4"
```

### 4. 运行测试
```bash
./run_test.sh
```

或者直接运行：
```bash
go run index_performance.go
```

## 📝 详细步骤

### 步骤 1：确保 MySQL 运行

检查 MySQL 是否运行：
```bash
mysql -u root -p -e "SELECT 1"
```

如果未运行，启动 MySQL：
```bash
# macOS
brew services start mysql

# Linux
sudo systemctl start mysql

# Docker
docker-compose up -d db
```

### 步骤 2：确认数据库存在

```bash
mysql -u root -p -e "SHOW DATABASES LIKE 'todo_app_go_frame'"
```

如果不存在，创建数据库：
```bash
mysql -u root -p -e "CREATE DATABASE todo_app_go_frame"
```

### 步骤 3：配置连接信息

根据你的环境修改 `config.yaml`：

**本地开发环境：**
```yaml
database:
  default:
    link: "mysql:root:123456@tcp(127.0.0.1:3306)/todo_app_go_frame?charset=utf8mb4"
```

**Docker 环境：**
```yaml
database:
  default:
    link: "mysql:gouser:gopassword@tcp(db:3306)/todo_db?charset=utf8mb4"
```

### 步骤 4：运行测试

使用脚本（推荐）：
```bash
./run_test.sh
```

直接运行：
```bash
go run index_performance.go
```

### 步骤 5：等待结果

测试过程约 5-10 分钟，你会看到：
- 🔧 创建测试表
- 📊 插入数据进度条
- 🔑 创建索引
- 📌 6 个测试场景的性能对比
- 📊 汇总结果

## 🐛 常见问题

### ❌ 错误 1：缺少 MySQL 驱动

**错误信息：**
```
panic: cannot find database driver for specified database type "mysql"
```

**解决方案：**
```bash
go get github.com/gogf/gf/contrib/drivers/mysql/v2
```

代码已经包含了驱动导入，只需安装依赖即可。

---

### ❌ 错误 2：连接数据库失败

**错误信息：**
```
Error 1045: Access denied for user 'root'@'localhost'
```

**解决方案：**
1. 检查 `config.yaml` 中的用户名和密码
2. 确认数据库用户有访问权限

---

### ❌ 错误 3：数据库不存在

**错误信息：**
```
Error 1049: Unknown database 'todo_app_go_frame'
```

**解决方案：**
```bash
mysql -u root -p -e "CREATE DATABASE todo_app_go_frame"
```

---

### ❌ 错误 4：插入太慢

**解决方案：**
修改 `index_performance.go` 第 19 行：
```go
const (
    TotalRecords = 100000  // 改为 10 万条
    BatchSize = 10000
)
```

---

### ❌ 错误 5：内存不足

**解决方案：**
1. 减少数据量到 10 万或 5 万
2. 增加 BatchSize（但不要超过 20000）

## 🎮 进阶使用

### 1. 自定义数据量

编辑 `index_performance.go`：
```go
const (
    TotalRecords = 500000  // 50 万条
    BatchSize = 10000      // 每批 1 万条
)
```

### 2. 添加自定义测试场景

在 `runPerformanceTests` 函数中添加：
```go
{
    name: "自定义查询",
    query: func(db gdb.DB, table string) (interface{}, error) {
        return db.Model(table).
            Where("user_id > ?", 5000).
            Order("created_at DESC").
            Limit(100).
            All()
    },
},
```

### 3. 修改索引策略

在 `addIndexes` 函数中修改：
```go
indexes := []struct {
    name string
    sql  string
}{
    {"user_id", "CREATE INDEX idx_user ON test_todo_with_index(user_id)"},
    // 添加或修改其他索引
}
```

### 4. 查看执行计划

测试完成后，进入 MySQL：
```bash
mysql -u root -p todo_app_go_frame
```

查看执行计划：
```sql
-- 无索引表
EXPLAIN SELECT * FROM test_todo_no_index WHERE user_id = 5000;

-- 有索引表
EXPLAIN SELECT * FROM test_todo_with_index WHERE user_id = 5000;
```

对比 `type` 列：
- `ALL` = 全表扫描（慢）
- `ref` = 使用索引（快）

### 5. 清理测试数据

测试完成后：
```bash
mysql -u root -p todo_app_go_frame < cleanup.sql
```

或手动删除：
```sql
DROP TABLE IF EXISTS test_todo_no_index, test_todo_with_index;
```
