# ⚠️ 重要：首次运行前必读

## 问题：缺少 MySQL 驱动

如果你运行时看到这个错误：
```
panic: cannot find database driver for specified database type "mysql"
```

这是因为 GoFrame v2 需要单独安装 MySQL 驱动。

---

## ✅ 解决方案（二选一）

### 方案 1：修改测试程序（推荐）

在 `index_performance.go` 文件的**开头**添加 MySQL 驱动导入：

```go
package main

import (
	"context"
	"fmt"
	"math/rand"
	"strings"
	"time"

	"github.com/gogf/gf/v2/database/gdb"
	"github.com/gogf/gf/v2/frame/g"
	"github.com/gogf/gf/v2/os/gctx"
	
	// 添加这一行 - 导入 MySQL 驱动
	_ "github.com/gogf/gf/contrib/drivers/mysql/v2"
)
```

然后安装驱动：
```bash
cd back-end/test
go get github.com/gogf/gf/contrib/drivers/mysql/v2
go run index_performance.go
```

### 方案 2：在项目根目录运行

因为你的主项目 `back-end` 已经安装了 MySQL 驱动，可以这样运行：

```bash
# 回到 back-end 目录
cd back-end

# 运行测试程序（指定 test 目录的配置文件）
GF_GCFG_FILE=test/config.yaml go run test/index_performance.go
```

## 🚀 推荐：方案 1（独立运行）

### 步骤 1：修改代码
在 `index_performance.go` 第 4 行后添加：
```go
import (
	// ... 其他导入 ...
	
	// 添加 MySQL 驱动
	_ "github.com/gogf/gf/contrib/drivers/mysql/v2"
)
```

### 步骤 2：安装依赖
```bash
cd back-end/test
go mod init test  # 如果没有 go.mod
go get github.com/gogf/gf/v2
go get github.com/gogf/gf/contrib/drivers/mysql/v2
```

### 步骤 3：配置数据库
编辑 `config.yaml`：
```yaml
database:
  default:
    link: "mysql:root:你的密码@tcp(127.0.0.1:3306)/todo_app_go_frame?charset=utf8mb4"
```

### 步骤 4：运行
```bash
./run_test.sh
# 或
go run index_performance.go
```

---

## 💡 为什么需要单独安装？

GoFrame v2 使用了模块化设计，数据库驱动是独立的 contrib 包，需要：
1. 显式导入驱动包
2. 使用 `_` 前缀进行副作用导入（仅初始化驱动）

这是 Go 标准的数据库驱动加载方式。

## 📝 完整的 import 示例

```go
package main

import (
	"context"
	"fmt"
	"math/rand"
	"strings"
	"time"

	"github.com/gogf/gf/v2/database/gdb"
	"github.com/gogf/gf/v2/frame/g"
	"github.com/gogf/gf/v2/os/gctx"
	
	_ "github.com/gogf/gf/contrib/drivers/mysql/v2"  // MySQL 驱动
)
```

运行后应该看到：
```
======================================================================
               🚀 数据库索引性能测试程序
======================================================================
📊 测试数据量: 1,000,000 条
⏰ 开始时间: 2026-06-16 16:51:03
======================================================================

🔧 正在创建测试表...
   ✓ 测试表创建成功
```

如果还是报错，检查：
1. 数据库是否启动
2. 配置文件中的连接信息是否正确
3. 数据库名称是否存在
